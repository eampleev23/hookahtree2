# Перенос на Netcup

13 ноября 2026. Переключение завершено: DNS направлен на Netcup, публичные HTTPS-проверки пройдены.

Владелец поручил перенести все проекты с SimpleCloud. Новый сервер:
`62.83.86.239`, административный доступ `ssh ampleev-netcup`.

Push в `main` собирает артефакт на GitHub и передаёт его ограниченному
пользователю `deploy-hookahtree2`. Ключ не даёт shell, sudo произвольных
команд или доступ к Docker. Публикация переключает готовый артефакт и проверяет
здоровье; при неудаче возвращает предыдущую версию. Базы и загруженные файлы
находятся вне каталогов релизов. Постоянный тестовый шаг перед production не
добавлялся; уже существующие тестовые экземпляры сохраняются.

Инфраструктура и root-owned правила выпуска: `eampleev23/ampleev-infra`,
каталог `migration/`. Код root-helper не обновляется из репозитория приложения.
Параметры приложения и прежние секреты сохранены в `/etc/migration/`;
их изменение выполняется отдельно через административную конфигурацию.
Не возвращать self-hosted runner или старый SSH-деплой на SimpleCloud.

Финальная копия БД и файлов перенесена после остановки старых записывающих
служб. Проверено совпадение числа строк всех таблиц. Журнал переключения,
архивы и список проверок: `eampleev23/ampleev-infra/migration/README.md`.
